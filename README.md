# RoastLab — контрольная работа №3

Тема — адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта. Выполнил Кирштейн Роберт, ЭФБО-07-25.

## Запуск

Откройте `index.html` в браузере. Сайт работает локально на HTML, CSS и JavaScript без Bootstrap и сборки. Основа стилей взята из архива КР №1. Сохранены шесть страниц RoastLab, фотографии, каталог на 18 товаров, галерея, формы и FAQ.

## Структура

- `index.html` — главная с подборкой товаров.
- `catalog.html` и `category-coffee.html` — каталог и раздел зернового кофе.
- `product.html` — карточка товара с галереей и таблицей характеристик.
- `order.html` и `contacts.html` — заявка и контакты.
- `css/style.css` — базовое оформление компонентов.
- `css/responsive.css` — адаптивная раскладка всех страниц.
- `images/` — фотографии и варианты малого размера.
- `js/main.js` — фильтры, галерея и проверка заявки.

## Практика №12

На каждой странице есть `viewport`. Адаптивные стили подключены после базовых. По подходу Mobile First исходная сетка одноколоночная, а медиазапросы `min-width` расширяют её.

| Ширина | Раскладка |
| --- | --- |
| До 639 px | Карточки, баннер и кнопки формы в одну колонку. Навигация переносится на несколько строк. |
| От 640 px | Две карточки в строке. Кнопки формы могут размещаться рядом. |
| От 768 px | Баннер, подробная карточка товара и контакты разбиваются на две колонки. |
| От 1024 px | Фильтр уходит в левую колонку. Товарные подборки и отзывы занимают три колонки. |
| От 1200 px | Каталог показывает три товара в строке. |

Для карточек `srcset` и `sizes` помогают браузеру выбрать изображение шириной 252 или 504 пикселя. В баннере используется `picture`. Изображения ограничены шириной контейнера. На узких экранах таблица характеристик прокручивается внутри собственной области. Заявка сохраняет одноколоночные поля, а окно заказа ограничено высотой экрана.

## Проверка

Проверены все шесть страниц в Edge при ширинах 360, 430, 768, 1024 и 1440 px. Горизонтальной прокрутки страницы и ошибок в консоли не обнаружено. Также проверены фильтр по категории и цене, галерея, выбор товара, невалидная и успешная отправка демонстрационной заявки.
